# Data Directory

Place your sample images in this directory for use in the workshop notebooks and scripts.

## Supported Formats
- JPEG (.jpg, .jpeg)
- PNG (.png)
- BMP (.bmp)
- TIFF (.tif, .tiff)
- And other common image formats supported by OpenCV

## Example
```
data/
├── sample1.jpg
├── sample2.png
└── test_image.jpg
```
